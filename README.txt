打撃フォーム分析 Web版 v1.9（解析品質重視版）
================================================

この版の重要ポイント
--------------------
・解析方式は MediaPipe Pose Landmarker Heavy の高精度固定です。
・解析前に「打者だけを赤枠で囲む」方式を使用します。
・フォーム類似度とは別に「解析信頼度」を表示します。
・インパクト周辺の骨格品質が不足する動画は、無理に結果を出さず解析を停止します。
・補間フレームを速度計算へ極力使わないよう変更しています。
・身体負担は0〜100の怪我リスク風スコアではなく、根拠別の段階判定です。

起動方法
--------
初回のみ:
  setup_web_app.bat

通常起動:
  start_web_app.bat

同じWi-Fiのスマートフォンから使う:
  start_web_app_network.bat
  → 黒い画面に表示される Network URL をスマホで開いてください。

基本手順
--------
1. 比較選手と自分の動画をアップロード
2. 右打者 / 左打者を選択
3. 8項目から比較する5項目を選択
4. 赤枠に打者のスイング全体だけが入るよう、横位置と幅を調整
5. 解析開始
6. 解析信頼度を確認
7. インパクトフレームを目視確認
8. 必要なら、実測骨格のあるフレームへ手動補正
9. PDFレポートを保存

解析信頼度
----------
80〜100 : 高
60〜79  : 要注意（結果は表示するが目視確認推奨）
60未満  : 解析不可

さらに以下の条件が不足する場合も解析を停止します。
・インパクト前後の骨格検出率
・連続検出フレーム
・実測フレーム間の連続性
・主要関節visibility

身体負担関連動作
----------------
怪我する確率を推定するものではありません。
先行研究で論点となった動作について、比較選手との差を段階表示します。

判定例:
・明確な増大なし
・やや注意
・注意要素あり
・評価困難

「比較選手より低い」ことは「安全」を意味しません。
